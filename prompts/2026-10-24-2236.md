### Response

The REFACTOR is done: every auth test now uses the new test helpers, all **25 tests still pass**, and ruff is clean across the whole backend. Only test files changed.

**New: `tests/factories.py`**
- **`make_user(email=..., password=..., role="user")`** saves a user straight to the database with a properly hashed password and returns it. It's a fixture that hands back a function, so tests call it like a normal function. It depends on `client` because the app creates the tables when it starts.
- **`auth_headers(user)`** returns `{"Authorization": "Bearer <token>"}`. The token comes from the real `TokenService` using the test settings.
- **`PASSWORD`** is the shared test password.
- `conftest.py` imports both fixtures so every test file can use them.

**Where they're used now**
- **`test_require_admin.py`**: the helper that registered, logged in and then changed the role in the database is gone. The admin test is now just `make_user(role="admin")`.
- **`test_current_user.py`**: the `register_and_login` and `bearer` helpers are gone. The deleted-user test now fetches the row by `user.id` instead of going through `UserRepository`.
- **`test_auth.py`**:
  - The duplicate-email, case-insensitive-email and both login tests now create their starting user with `make_user`.
  - Tests that check registration itself still go through the endpoint, since that's what they test.
  - Ruff reformatted this file, which also fixed the 5 old line-length errors.

**Coverage change:** the valid-token test now gets its token from `TokenService.issue` instead of calling `/login`. The login endpoint's token is still checked on its own in `test_login_returns_bearer_token_with_user_claims`.
