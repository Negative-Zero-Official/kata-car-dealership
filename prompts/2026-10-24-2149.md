**What changed:**

A single `handle_domain_error` returns `{"detail": ...}`, the same response body as before. `register_exception_handlers(app)` registers a handler for each error in the table.
- **`app/factory.py`:** now calls `register_exception_handlers(app)`.

- **`app/routes/auth.py`:** the route is back to having no `try/except`.

To add a new domain error from now on, subclass `DomainError` and add one entry to `STATUS_BY_ERROR`.
