### Response

GREEN is done: all 17 invalid-payload cases now get a 422, and the full backend suite passes (55 passed), with ruff check and format both clean.

The only file changed is `backend/app/schemas/vehicle.py`. The rules are on `VehicleBase`:
- **make, model, category:** a new `NonBlankStr` type that strips surrounding whitespace and needs at least 1 character left. So `"   "` is rejected and `"  Toyota "` is stored as `"Toyota"`.
- **price:** `Money` that must be more than 0 and have at most 2 decimal places.
- **quantity:** a whole number of 0 or more.

`VehicleRead` gets the same rules because it inherits from `VehicleBase`. Values read back from the database already meet them, so nothing changes there.

I didn't add `max_digits=12` to match the database's `Numeric(12, 2)` column, because no test needs it yet. Without it, a very large price passes validation and I haven't checked what the database does with it.

Nothing is committed yet. When you ask, the message will be `(GREEN) feat: validate vehicle input`.
