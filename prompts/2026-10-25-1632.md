### Response

GREEN step is done: a purchase can now take a quantity. The full suite passes (`uv run pytest -q`: **103 passed**) and ruff check and format are clean.

Changes:
- **`app/schemas/vehicle.py`:** new `PurchaseRequest` with `quantity: Annotated[int, Field(gt=0)] = 1`. Pydantic's `int` rejects `1.5` on its own, so `gt=0` handles `0` and `-1`.
- **`app/routes/vehicles.py`:** the purchase route takes an optional `request: PurchaseRequest | None = None` body. With no body it falls back to `PurchaseRequest().quantity`, which is 1, so the original no-body test still passes. It then calls `service.purchase(vehicle_id, quantity)`.
- **`app/services/inventory.py`:** `purchase` takes `quantity` and subtracts it instead of 1.

This doesn't add a stock check: buying more than is in stock will still push the quantity below zero.

One possible REFACTOR: the `| None` plus fallback line is a bit clunky. A default of `PurchaseRequest()` on the parameter would remove the fallback.
