### Response

GREEN is done: the full suite passes (`uv run pytest -q`: **117 passed**), and ruff check and format are clean.

What changed:
- **`app/repositories/vehicle.py`:** new `VehicleRepository.increment(vehicle_id, amount)`. It adds the stock with one `UPDATE … SET quantity = quantity + :n WHERE id = :id`, commits, and returns `rowcount == 1`. That's the atomic pattern the ADR called for, so two restocks can't lose each other's update.
- **`app/services/inventory.py`:** new `InventoryService.restock`. If no row was updated it raises `VehicleNotFound` (404); otherwise it reloads the vehicle and returns it.
- **`app/schemas/vehicle.py`:** new `RestockRequest` with `quantity: int > 0` and no default. A missing body, `{}`, 0 or a negative number all give a 422.
- **`app/routes/vehicles.py`:** new `POST /{vehicle_id}/restock` route, protected by `require_admin` (403 for regular users).

One thing to look at in REFACTOR: `restock` uses `assert vehicle is not None` after the reload. Only a delete landing between the UPDATE and the reload could trigger it.
