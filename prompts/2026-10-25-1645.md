What changed:
- **`app/repositories/vehicle.py`:** I added `try_decrement(vehicle_id, amount)`. It runs one statement, `UPDATE vehicles SET quantity = quantity - :n WHERE id = :id AND quantity >= :n`, then commits and returns `rowcount == 1`. Checking and subtracting the stock now happen in that single UPDATE, so two buyers can't both pass the check on the same stock.

  - vehicle missing → `VehicleNotFound` (404)
  - decrement refused → `InsufficientStock` (409)
  - otherwise → returns the vehicle with its updated stock

  Each of these outcomes already had a test.

The service no longer uses `VehicleRepository.save`, but `VehicleService.update` still does, so I left it in.
